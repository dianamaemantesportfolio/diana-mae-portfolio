# Diana Mae Mantes — Virtual Assistant Portfolio

A responsive static website built with HTML, CSS, and vanilla JavaScript. It is ready to publish on GitHub Pages.

## Files
- `index.html` — website content and structure
- `styles.css` — responsive layout and visual design
- `script.js` — mobile navigation, smooth section links, and current footer year
- `assets/` — four supplied photos (kept unchanged) and the supplied résumé PDF

## Preview locally
1. Unzip the package.
2. Open `index.html` in a modern browser.
3. For a closer match to hosting, you can use VS Code's Live Server extension or run a simple local HTTP server.

The site uses Google Fonts (Playfair Display and Poppins, with fallbacks). If external fonts are unavailable, it falls back to installed serif and sans-serif fonts. The email CTA uses a `mailto:` link and opens the visitor's configured email application.

## Publish free with GitHub Pages
1. Sign in to GitHub or create a free account at https://github.com.
2. Click **New repository**. Name it `diana-mae-portfolio` (or another name), choose **Public**, and create the repository.
3. On the new repository page, choose **Add file → Upload files**.
4. Extract this ZIP on your computer. Upload the contents of the extracted `diana-mae-virtual-assistant-portfolio` folder—not the ZIP itself. Make sure `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder are at the repository's top level.
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**. Select branch `main` and folder `/(root)`, then click **Save**.
8. Wait a few minutes and refresh the Pages settings. GitHub will show the published URL, usually `https://YOUR-USERNAME.github.io/diana-mae-portfolio/`.
9. Open the URL on both desktop and mobile. If you update content later, commit the changed files and GitHub Pages will redeploy.

## Before sharing publicly
- Check that `virtualassistancewithdiana@gmail.com` is the best public contact address.
- Consider whether you want your résumé PDF publicly downloadable. It is included in `assets/` and linked from the website.
- The site deliberately does not invent client metrics, testimonials, or work samples. The portfolio section clearly labels its cards as capability summaries, not client deliverables.
- Photos were copied from the files you uploaded without editing.

## Quick customization
- Update text and section content in `index.html`.
- Change the color variables at the top of `styles.css`.
- Replace the email address in the `mailto:` link and visible email text if it changes.
- Add genuine project samples to `assets/` and update the portfolio section when you are ready.
